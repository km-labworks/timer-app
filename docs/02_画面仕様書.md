# 2. 画面一覧

本システムで提供する画面を以下に示す。

| 画面ID    | 画面名        | 概要                  |
| ------- | ---------- | ------------------- |
| SCR-001 | タイマー画面     | タイマーの設定および計測を行う。    |
| SCR-002 | アラーム画面     | アラームの登録・編集・削除を行う。   |
| SCR-003 | ストップウォッチ画面 | 経過時間の計測およびラップ記録を行う。 |

---

# 3. 共通仕様

## 3.1 画面構成

すべての画面は、画面上部のタブから切り替えて利用できる。

* タイマー
* アラーム
* ストップウォッチ

現在表示中の画面は、選択状態が分かるデザインとする。

---

## 3.2 共通デザイン

* 画面上部に機能切替タブを配置する。
* メイン機能は画面中央へ配置する。
* 操作ボタンは画面下部へ配置する。
* スマートフォンおよびPCの両方で利用できるレイアウトとする。

---

## 3.3 共通操作

* タブを押下すると対象画面へ切り替える。
* 画面切替時もタイマーおよびストップウォッチは継続して動作する。
* アラーム情報は保持したまま画面を切り替える。

# 4. SCR-001 タイマー画面

## 4.1 画面概要

タイマー画面は、利用者が時間・分・秒を設定し、タイマーの開始・一時停止・再開・キャンセルを行う画面である。

タイマー動作中は残り時間を表示し、終了時には通知音を鳴らす。

---

## 4.2 画面レイアウト

画面は以下の構成とする。

```text
┌─────────────────────────────┐
│ Timer │ Alarm │ Stopwatch │
├─────────────────────────────┤
│                             │
│       00 : 00 : 00          │
│                             │
├─────────────────────────────┤
│ 時間 │ 分 │ 秒             │
│ □□  │ □□ │ □□             │
├─────────────────────────────┤
│ 開始 │ 一時停止 │ キャンセル │
└─────────────────────────────┘
```

---

## 4.3 画面項目一覧

| No | 項目名      | 種別       | 説明                        |
| -- | -------- | -------- | ------------------------- |
| 1  | タブ       | タブ       | タイマー・アラーム・ストップウォッチを切り替える。 |
| 2  | 残り時間表示   | ラベル      | 残り時間を表示する。                |
| 3  | 時間入力     | テキストボックス | 時間を入力する。                  |
| 4  | 分入力      | テキストボックス | 分を入力する。                   |
| 5  | 秒入力      | テキストボックス | 秒を入力する。                   |
| 6  | 開始ボタン    | ボタン      | タイマーを開始する。                |
| 7  | 一時停止ボタン  | ボタン      | タイマーを一時停止する。              |
| 8  | キャンセルボタン | ボタン      | タイマーを停止し初期状態へ戻す。          |

---

## 4.4 ボタン仕様

| ボタン   | 動作                |
| ----- | ----------------- |
| 開始    | タイマーを開始する。        |
| 一時停止  | タイマーを一時停止する。      |
| 再開    | 一時停止中のタイマーを再開する。  |
| キャンセル | タイマーを停止し、初期状態へ戻す。 |

---

## 4.5 入力仕様

| 項目   | 内容          |
| ---- | ----------- |
| 時間   | 0～99を入力できる。 |
| 分    | 0～59を入力できる。 |
| 秒    | 0～59を入力できる。 |
| 入力形式 | 数字のみ入力できる。  |

---

## 4.6 入力チェック

| No | 条件       | 動作             |
| -- | -------- | -------------- |
| 1  | 00:00:00 | 開始ボタンを押下できない。  |
| 2  | 数字以外     | エラーメッセージを表示する。 |
| 3  | 範囲外の値    | 入力を受け付けない。     |
| 4  | 空欄       | エラーメッセージを表示する。 |

---

## 4.7 表示仕様

* タイマー開始後は残り時間を1秒ごとに更新する。
* 一時停止中は残り時間を保持する。
* タイマー終了後は「00:00:00」を表示する。

---

## 4.8 通知仕様

* タイマー終了時に通知音を再生する。
* 通知音は利用者が停止するまで鳴り続ける。

## 4.9 初期表示

画面初期表示時は以下の状態とする。

| 項目 | 初期状態 |
|------|----------|
| 残り時間表示 | 00:00:00 |
| 時間入力 | 空欄 |
| 分入力 | 空欄 |
| 秒入力 | 空欄 |
| 開始ボタン | 無効（00:00:00の場合） |
| 一時停止ボタン | 無効 |
| キャンセルボタン | 無効 |

## 4.10 ボタン状態

| 状態 | 開始 | 一時停止 | キャンセル |
|------|------|----------|------------|
| 初期 | 有効※ | 無効 | 無効 |
| 動作中 | 無効 | 有効 | 有効 |
| 一時停止中 | 再開 | 無効 | 有効 |
| 終了 | 有効 | 無効 | 無効 |

※開始ボタンは00:00:00以外が設定されている場合のみ有効とする。

## 4.11 画面状態

タイマー画面は以下の状態で動作する。

| 状態 | 説明 |
|------|------|
| 初期状態 | タイマー開始前の状態 |
| 動作中 | カウントダウン中 |
| 一時停止中 | カウントダウン停止中 |
| 終了 | カウントダウン完了後 |

# 5. SCR-002 アラーム画面

## 5.1 画面概要

アラーム画面は、利用者がアラームの登録、編集、削除、有効・無効の切り替えを行う画面である。

登録したアラームはブラウザのLocalStorageへ保存し、ブラウザを終了した後も保持する。

---

## 5.2 画面レイアウト

```text
┌─────────────────────────────┐
│ Timer │ Alarm │ Stopwatch │
├─────────────────────────────┤
│ 時間：□□ : □□             │
│                           │
│ ＋ アラーム追加            │
├─────────────────────────────┤
│ ☑ 07:00                 🗑 │
│ ☑ 08:30                 🗑 │
│ □ 18:00                 🗑 │
├─────────────────────────────┤
│        保存               │
└─────────────────────────────┘
```

---

## 5.3 画面項目一覧

| No | 項目名       | 種別       | 説明                |
| -- | --------- | -------- | ----------------- |
| 1  | タブ        | タブ       | 各機能を切り替える。        |
| 2  | 時間入力      | テキストボックス | 時間を入力する。          |
| 3  | 分入力       | テキストボックス | 分を入力する。           |
| 4  | アラーム追加ボタン | ボタン      | アラームを登録する。        |
| 5  | アラーム一覧    | リスト      | 登録済みアラームを表示する。    |
| 6  | 有効・無効チェック | チェックボックス | アラームの有効・無効を切り替える。 |
| 7  | 削除ボタン     | ボタン      | アラームを削除する。        |

---

## 5.4 ボタン仕様

| ボタン      | 動作                |
| -------- | ----------------- |
| アラーム追加   | 入力内容でアラームを登録する。   |
| チェックボックス | アラームの有効・無効を切り替える。 |
| 削除       | 選択したアラームを削除する。    |

---

## 5.5 入力仕様

| 項目   | 内容           |
| ---- | ------------ |
| 時間   | 0～23を入力できる。  |
| 分    | 0～59を入力できる。  |
| 入力形式 | 数字のみ入力できる。   |
| 登録件数 | 最大5件まで登録できる。 |

---

## 5.6 入力チェック

| No | 条件     | 動作             |
| -- | ------ | -------------- |
| 1  | 数字以外   | エラーメッセージを表示する。 |
| 2  | 範囲外の値  | 入力を受け付けない。     |
| 3  | 5件登録済み | 追加できない旨を表示する。  |
| 4  | 空欄     | エラーメッセージを表示する。 |

---

## 5.7 表示仕様

* 登録済みアラームを一覧表示する。
* 有効なアラームはチェック状態で表示する。
* 無効なアラームは未チェック状態で表示する。

---

## 5.8 通知仕様

* 設定時刻になると通知音を再生する。
* 通知音は停止操作が行われるまで再生する。

---

## 5.9 初期表示

| 項目     | 初期状態                        |
| ------ | --------------------------- |
| 時間入力   | 空欄                          |
| 分入力    | 空欄                          |
| アラーム一覧 | LocalStorageから読み込んだ内容を表示する。 |

---

## 5.10 画面状態

| 状態   | 説明              |
| ---- | --------------- |
| 初期状態 | アラーム一覧を表示している状態 |
| 登録後  | 一覧へ追加して表示する。    |
| 編集後  | 更新内容を反映して表示する。  |
| 削除後  | 一覧から削除して表示する。   |

---

## 5.11 メッセージ一覧

| メッセージID | メッセージ             | 表示条件          |
| ------- | ----------------- | ------------- |
| MSG101  | 時間を入力してください。      | 時間が未入力        |
| MSG102  | 分を入力してください。       | 分が未入力         |
| MSG103  | 0～23の範囲で入力してください。 | 時間が範囲外        |
| MSG104  | 0～59の範囲で入力してください。 | 分が範囲外         |
| MSG105  | アラームは5件まで登録できます。  | 登録件数が上限に達した場合 |

# 6. SCR-003 ストップウォッチ画面

## 6.1 画面概要

ストップウォッチ画面は、経過時間の計測およびラップタイムの記録を行う画面である。

利用者はストップウォッチの開始、停止、リセットおよびラップタイムの記録を行うことができる。

---

## 6.2 画面レイアウト

```text
┌─────────────────────────────┐
│ Timer │ Alarm │ Stopwatch │
├─────────────────────────────┤
│                             │
│      00:00:00.000           │
│                             │
├─────────────────────────────┤
│ 開始 │ 停止 │ ラップ │ リセット │
├─────────────────────────────┤
│ ラップ一覧                  │
│ Lap1 00:00:10.235           │
│ Lap2 00:00:18.642           │
│ Lap3 00:00:27.511           │
└─────────────────────────────┘
```

---

## 6.3 画面項目一覧

| No | 項目名     | 種別  | 説明                        |
| -- | ------- | --- | ------------------------- |
| 1  | タブ      | タブ  | タイマー、アラーム、ストップウォッチを切り替える。 |
| 2  | 経過時間表示  | ラベル | 現在の経過時間を表示する。             |
| 3  | 開始ボタン   | ボタン | 計測を開始する。                  |
| 4  | 停止ボタン   | ボタン | 計測を停止する。                  |
| 5  | ラップボタン  | ボタン | 現在の計測時間をラップタイムとして記録する。    |
| 6  | リセットボタン | ボタン | 計測時間およびラップタイムを初期状態へ戻す。    |
| 7  | ラップ一覧   | リスト | 記録したラップタイムを表示する。          |

---

## 6.4 ボタン仕様

| ボタン  | 動作                     |
| ---- | ---------------------- |
| 開始   | ストップウォッチを開始する。         |
| 停止   | 計測を停止する。               |
| ラップ  | 現在の計測時間をラップタイムとして記録する。 |
| リセット | 計測時間およびラップタイムを初期状態へ戻す。 |

---

## 6.5 表示仕様

| 項目      | 内容                      |
| ------- | ----------------------- |
| 表示形式    | 時:分:秒.ミリ秒（HH:MM:SS.mmm） |
| 更新タイミング | 計測中はリアルタイムに更新する。        |
| ラップ表示   | ラップタイムを記録順に一覧表示する。      |

---

## 6.6 動作仕様

* 計測開始後は経過時間を継続して表示する。
* 停止後は経過時間を保持する。
* 再度開始した場合は停止時点から計測を再開する。
* ラップボタン押下時は現在の計測時間を一覧へ追加する。
* リセット時は計測時間を「00:00:00.000」に戻し、ラップ一覧をクリアする。

---

## 6.7 初期表示

| 項目      | 初期状態         |
| ------- | ------------ |
| 経過時間表示  | 00:00:00.000 |
| 開始ボタン   | 有効           |
| 停止ボタン   | 無効           |
| ラップボタン  | 無効           |
| リセットボタン | 無効           |
| ラップ一覧   | 空            |

---

## 6.8 ボタン状態

| 状態    | 開始     | 停止 | ラップ | リセット |
| ----- | ------ | -- | --- | ---- |
| 初期    | 有効     | 無効 | 無効  | 無効   |
| 計測中   | 無効     | 有効 | 有効  | 有効   |
| 停止中   | 有効（再開） | 無効 | 無効  | 有効   |
| リセット後 | 有効     | 無効 | 無効  | 無効   |

---

## 6.9 画面状態

| 状態    | 説明            |
| ----- | ------------- |
| 初期状態  | 計測前の状態        |
| 計測中   | 経過時間を計測している状態 |
| 停止中   | 計測を一時停止している状態 |
| リセット後 | 初期状態へ戻った状態    |

---

## 6.10 メッセージ一覧

本画面では、通常操作において利用者へ表示するエラーメッセージはない。

---

## 6.11 備考

* ラップタイムの記録件数に制限は設けない。
* ラップタイムはリセット時にすべて削除する。
* ストップウォッチの状態はブラウザ終了後も保持しない。

# 7. 画面遷移図

## 7.1 画面遷移概要

本システムは、タイマー、アラーム、ストップウォッチの3画面で構成される。

利用者は画面上部のタブを選択することで、任意の画面へ切り替えることができる。

画面切替時も、動作中のタイマーおよびストップウォッチは継続して動作する。

---

## 7.2 画面遷移図

```text
                ┌───────────────┐
                │  SCR-001      │
                │ タイマー画面   │
                └──────┬────────┘
                       ▲│
                       │▼
                ┌───────────────┐
                │  SCR-002      │
                │ アラーム画面   │
                └──────┬────────┘
                       ▲│
                       │▼
                ┌───────────────┐
                │  SCR-003      │
                │ ストップウォッチ画面 │
                └───────────────┘
```

---

## 7.3 画面遷移一覧

| 遷移元                | 操作            | 遷移先                |
| ------------------ | ------------- | ------------------ |
| SCR-001 タイマー画面     | アラームタブを押下     | SCR-002 アラーム画面     |
| SCR-001 タイマー画面     | ストップウォッチタブを押下 | SCR-003 ストップウォッチ画面 |
| SCR-002 アラーム画面     | タイマータブを押下     | SCR-001 タイマー画面     |
| SCR-002 アラーム画面     | ストップウォッチタブを押下 | SCR-003 ストップウォッチ画面 |
| SCR-003 ストップウォッチ画面 | タイマータブを押下     | SCR-001 タイマー画面     |
| SCR-003 ストップウォッチ画面 | アラームタブを押下     | SCR-002 アラーム画面     |

---

## 7.4 遷移時の動作

* タイマー動作中に他画面へ遷移した場合でも、タイマーは継続して動作する。
* ストップウォッチ計測中に他画面へ遷移した場合でも、計測は継続する。
* アラーム画面へ遷移しても登録済みアラームは保持される。
* 各画面へ戻った際は、最新の状態を表示する。
